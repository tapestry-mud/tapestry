# Scenario: drink command
# Setup: player carries "a water skin" (item_type=drink, charges=3) and "a steel blade" (item_type=weapon)

# Happy path: drink from a drinkable item
> drink skin
< You drink from a water skin.

# Error: no argument
> drink
< What item?

# Error: item not in inventory
> drink goblet
< You aren't carrying that.

# Error: item is not drinkable
> drink blade
< You can't drink that.

# Error: empty container (charges=0)
# Setup: "an empty flask" (item_type=drink, charges=0)
> drink flask
< It's empty.
